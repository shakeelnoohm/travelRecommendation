# TravelBloom - Travel Recommendation App

A web application for discovering dream travel destinations including beaches, temples, and cities around the world.

## Features

- **Search Functionality**: Search for destinations by keywords like "beach", "temple", or "country"
- **Destination Results**: View detailed information with images and descriptions
- **Local Time Display**: See current local time for each destination
- **Responsive Design**: Works on desktop and mobile devices
- **Contact Form**: Get in touch with the team
- **About Us**: Learn about the company and team

## Pages

- **Home**: Landing page with search functionality and social media links
- **About Us**: Company information and team members
- **Contact Us**: Form to send messages

## How to Run

1. Open `index.html` in your web browser
2. No server required - works directly in browser

## Search Instructions

Type one of these keywords in the search box:
- `beach` - Shows beach destinations
- `temple` - Shows temple destinations  
- `country` or `city` - Shows cities from various countries

Click **Search** to see results, **Reset** to clear.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- JSON for data storage
